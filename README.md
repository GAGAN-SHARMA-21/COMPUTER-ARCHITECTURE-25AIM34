## Assignment Overview

This repository contains Python programs for signed binary arithmetic and rotate operations using 8-bit binary representation.

## Question 1: Signed Binary Arithmetic

- 8-bit 2's complement representation.
- Addition and subtraction operations.
- Binary and decimal results.
- Arithmetic overflow detection.

**Expressions:**
1. (+46) + (+29)
2. (-48) - (-23)

**Files:** `Q1_Signed_Binary_Arithmetic.ipynb`

## Question 2: Rotate Operations

- Rotate Right Without Carry (ROR).
- Rotate Right With Carry (RCR).
- Step-by-step binary rotation.
- Carry flag verification.

**Operations:**
1. ROR on 11010101 by 3 positions.
2. RCR on 11010101 by 3 positions.

**Files:** `Q2_Rotate_Operations.ipynb`
